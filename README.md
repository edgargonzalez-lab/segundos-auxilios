# Sitio Web: Primeros Auxilios Básicos

## Descripción del proyecto
Sitio web informativo y educativo cuyo objetivo es enseñar a la población general los procedimientos básicos de primeros auxilios para actuar de forma rápida y segura ante emergencias comunes, mientras llega ayuda profesional.

## Objetivo general
Proporcionar información clara, accesible y confiable sobre técnicas de primeros auxilios, promoviendo la cultura de prevención y respuesta oportuna ante accidentes o emergencias médicas.

## Objetivos específicos
- Explicar paso a paso los procedimientos de primeros auxilios más comunes.
- Brindar contenido visual (imágenes/diagramas) que facilite el aprendizaje.
- Incluir números de emergencia y contactos útiles según el país.
- Fomentar la certificación y capacitación formal en primeros auxilios.

## Público objetivo
- Estudiantes.
- Padres de familia.
- Docentes.
- Personal de empresas (brigadas de emergencia).
- Público en general.

## Estructura del sitio (mapa de navegación)
1. **Inicio** – Presentación del sitio y su propósito.
2. **¿Qué son los primeros auxilios?** – Definición, importancia, principios básicos (evaluar, avisar, actuar).
3. **Emergencias comunes**
   - Heridas y cortes
   - Quemaduras
   - Fracturas y esguinces
   - Atragantamiento (maniobra de Heimlich)
   - Reanimación cardiopulmonar (RCP)
   - Desmayos y pérdida de conciencia
   - Picaduras y mordeduras
   - Convulsiones
   - Intoxicaciones
4. **Botiquín básico** – Lista de elementos esenciales.
5. **Números de emergencia** – Contactos según país/región.
6. **Recursos descargables** – Guías en PDF, infografías.
7. **Contacto / Sobre nosotros**

## Tecnologías sugeridas
- **Frontend:** HTML5, CSS3, JavaScript
- **Framework CSS (opcional):** Bootstrap o Tailwind
- **Control de versiones:** Git y GitHub
- **Hosting:** GitHub Pages, Netlify o Vercel
